# 한글 탐험대

예비 초등학생을 위한 모바일 한글 학습 웹앱입니다.

실행 주소: https://hangul-adventure.tiledluck.chatgpt.site/

## 주요 기능

- 6단계 배움 지도와 놀이형 진단
- 소리 찾기, 글자 조립, 낱말 찾기, 손글씨·받아쓰기, 이야기 읽기
- 한국어 AI 음성 파일과 토리 캐릭터 애니메이션
- 정답 축하 효과, 별 보상, 오답 기록
- 브라우저 내 진도 저장과 보호자 설정

## 로컬 실행

`dist` 폴더를 정적 HTTP 서버로 제공하면 됩니다. Python이 설치되어 있다면:

```sh
python -m http.server 4173 --directory dist
```

브라우저에서 http://localhost:4173 을 여세요. 실행 시 별도 API 키는 필요하지 않습니다.

## 검증

Node.js에서 `node verify.cjs`를 실행합니다. 학습 화면 구성, 정답 처리, 보상 중복 방지, 음성 파일 연결을 검사합니다.

## 파일 구성

- `dist/`: 배포 가능한 웹앱과 음성 파일
- `make-voices.cjs`: 한국어 음성 파일 제작 스크립트
- `verify.cjs`: 기능 및 음성 파일 검증
- `.openai/hosting.json`: 기존 Sites 배포 설정

## 현재 범위

음성은 AI 합성이며 실제 성우 녹음은 아닙니다. 손글씨는 정답 비교 방식이며 자동 필기 인식은 제공하지 않습니다. 현재 콘텐츠는 기초 첫 버전으로, 장기 학습용 확장과 교육 전문가 검토가 필요합니다. 진도는 사용하는 브라우저에만 저장됩니다.
